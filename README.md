# Amaana Foundation Platform

Foundation V1 for [amaanafoundation.org](https://amaanafoundation.org): a Next.js platform for verified charitable appeals and assistance requests.

## Local setup

1. Copy `.env.example` to `.env.local` and set `DATABASE_URL`.
2. Run `npm install`.
3. Run `npm run prisma:generate`.
4. Run `npm run dev`.

Use `npm run check` before submitting changes.
