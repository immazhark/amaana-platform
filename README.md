# Amaana Foundation Platform

Foundation V1 for [amaanafoundation.org](https://amaanafoundation.org): a Next.js platform for verified charitable appeals and assistance requests.

## Local setup

1. Copy `.env.example` to `.env.local` and set `DATABASE_URL`.
2. Run `npm install`.
3. Run `npm run prisma:generate`.
4. Run `npm run dev`.

Use `npm run check` before submitting changes.

## Operations

- Apply the Prisma schema to PostgreSQL before starting the application.
- Run `npm run seed:rbac` after configuring the three initial administrator accounts.
- Configure a Razorpay webhook at `/api/webhooks/razorpay` for `payment.captured`, `payment.failed`, and `refund.processed`.
- Use Razorpay test credentials and test webhooks before switching to live keys.
- Donation documents generated by the platform are acknowledgements only; they are not Section 80G certificates.
