## Architecture filter

Amaana already runs Next.js App Router, strict TS/React, Prisma/PostgreSQL, Razorpay, Railway, existing Playwright/Vitest and official brand. First adopt methods that improve regression evidence, authorization boundary inspection, frontend QA and scoped security review. Additional agents, proxies, credentials, telemetry, GPU/media stacks and donor-data handlers require separate evaluation. No wholesale dependency adoption or protected-main push.
